## Architecture Pattern Used

All diagrams follow a consistent structure:

```
📁 diagram-type/
├── NN-diagram-name-template.svg         (Data-driven template)
└── ../scripts/diagram-type/
    ├── __init__.py                      (Module exports)
    └── diagram_converter.py             (Converter class)
```

Each SVG contains:
- JSON metadata block (title, description, version)
- CSS styling (colors, fonts, design tokens)
- SVG visual elements
- JS validation for JSON data

Each converter implements:
- `render_diagram()` method
- Visio shape generation
- Connector/relationship mapping
- Color and styling application
